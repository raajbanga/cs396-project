C1 [x] Parser src/lib/describe-search.ts (pure, no DB):
       parseDescription(text, vocab) → { filters: Partial<FacilityFilters>,
       tab?: "explorer"|"units", sort?: {by, dir}, qualitative:
       {metric, level:"high"|"low"}[], matched: {text, key, value}[],
       unrecognized: string[] }.
       Order-independent entity extraction (not sentence templates):
       - Normalize: lowercase, CO₂→co2, strip punctuation except . , - > <.
       - Greedy longest n-gram match (≤4 words) so "natural gas", "new york",
         "west virginia" beat "gas"/"york"/"virginia".
       - Vocab = getFilterOptions (states, fuels, secondary fuels, unit types,
         SO₂/NOₓ/PM controls, counties, years) + static tables:
           · US state names → codes
           · synonyms: gas → Natural Gas, coal-fired → Coal, scrubber/FGD →
             SO₂ control, SCR/low-NOx burner → NOₓ control, baghouse →
             Fabric Filter, ESP → Electrostatic, combined cycle, …
           · metric words: co2/carbon, so2/sulfur, nox/nitrogen, heat input,
             generation/gross load/output/MWh, operating time/hours
           · views: unit(s)/generator/boiler → units; plant/facility →
             facilities
           · status: operating/active, retired
       - Two-letter codes count only when typed in UPPERCASE ("IN", "OR",
         "ME" are English words). Counties need the word "county".
       - Fuzzy match (Damerau-Levenshtein ≤ 1, words ≥ 5 chars) for state and
         fuel names ("Kentuky", "natual gas").
       - Numbers: 500,000 · 500k · 1.2M · 5e5. Comparators: >, <, ≥, over,
         above, more/greater than, at least, under, below, less than, at most,
         between A and B. A comparator binds to the nearest metric word in the
         same clause, in either order. A unit word disambiguates (tons needs
         a pollutant word; MWh → generation; hr → hours; MMBtu → heat input).
       - Years: "2025" → year; "2015-2025" / "from 2015 to 2025" / "since
         2020" → yearMin/yearMax.
       - Ranking: top/highest/largest/most [N] → sort desc (+ topN, default 10
         when N is omitted); bottom/lowest/least/cleanest → asc; "per state" /
         "in each state" → rankGroup=state. "high/low <metric>" without N →
         qualitative.
       - Stopwords dropped (find, show, me, with, in, the, emissions, …).
         Anything left → unrecognized.
